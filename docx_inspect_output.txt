[111] style=Heading 3            align=JUSTIFY (3) text=' The "Ghost Echo" Bug (Sonar Calibration)'
[112] style=normal               align=JUSTIFY (3) text='The Mishap: Initially, the sonar was giving "ghost" readings of 4-6 inches even when the path was clear.'
[113] style=normal               align=JUSTIFY (3) text='The Discovery: The 1.5-inch PVC pipe was so rigid that the vibration from the haptic motors was "tricking" the ultrasonic sensor into thinking the vibration sound was a returned ping.'
[114] style=normal               align=JUSTIFY (3) text='The Fix: We implemented "Actuator-Sensor Interleaving." Added code to pause the motors for 40ms before every ping to ensure a "quiet" environment for the sonar.'
[115] style=Heading 3            align=JUSTIFY (3) text='The I2C Address Conflict'
[116] style=normal               align=JUSTIFY (3) text="The Mishap: When first plugging in the ToF sensor and the XIAO S3, the system wouldn't boot."
[117] style=normal               align=JUSTIFY (3) text='The Discovery: Multiple sensors were trying to use the same I2C data bus pins, causing a "Bus Hang."'
[118] style=normal               align=JUSTIFY (3) text='The Fix: We had to manually re-assign the SDA/SCL pins in the code and use a pull-up resistor circuit to stabilize the data signal over the long wire runs inside the PVC pipe.'
[119] style=Heading 3            align=JUSTIFY (3) text='The BLE "Security Wall" (The Web App Issue)'
[120] style=normal               align=JUSTIFY (3) text='The Mishap: We successfully connected the cane as a Bluetooth Keyboard, but the Web App couldn\'t "talk back" to change modes.'
[121] style=normal               align=JUSTIFY (3) text='The Discovery: Modern mobile browser security (Web Bluetooth API) prevents a website from sending data to a device already paired as an HID Keyboard to prevent keylogging.'
[122] style=normal               align=JUSTIFY (3) text='The Fix: We pivoted to a "One-Way Control Architecture." The handle buttons control the phone app, and the cane\'s internal logic handles the sensors independently, ensuring the user is never left without feedback if the phone disconnects.'
